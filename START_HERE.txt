🚀 UNTUK MULAI (3 LANGKAH CEPAT):

1️⃣  Buka Command Prompt:
    cd c:\xampp\htdocs\Simjar_dispusip

2️⃣  Install Dependencies:
    composer install

3️⃣  Setup Database & Jalankan:
    php artisan migrate --seed

   - Jalankan: php artisan serve
   ➜ http://127.0.0.1:8000

C) Dengan Virtual Host (Lihat INSTALLATION.md):
   ➜ http://simjar.local

🗄️ DATABASE:

Tables:
├── barang_masuk
│   └─ Data barang yang masuk ke sistem

│   └─ Data inventaris perangkat jaringan
└── activity_logs

═══════════════════════════════════════════════════════════════

⚙️  KONFIGURASI PENTING:

File: .env

DB_DATABASE=simjar_db      (Nama database)
DB_USERNAME=root           (Username MySQL)
DB_PASSWORD=               (Password - kosong untuk XAMPP)
DB_HOST=127.0.0.1          (Host MySQL)

═══════════════════════════════════════════════════════════════

🔧 COMMAND PENTING:

php artisan migrate              → Run migrations
php artisan migrate:refresh      → Reset & re-run migrations
php artisan db:seed              → Insert sample data
php artisan cache:clear          → Clear cache
php artisan route:clear          → Clear route cache
php artisan storage:link         → Link storage folder
php artisan serve                → Start dev server
php artisan tinker               → Interactive shell

🆘 BANTUAN:

Jika Menemukan Error:

1) Database Error
   → Check .env konfigurasi database
   → Pastikan MySQL running
   → Run: php artisan migrate

2) Class Not Found
   → Run: composer install

3) CSS/JS Not Loading
   → Run: php artisan storage:link
   → Refresh browser (Ctrl + F5)

4) Route Not Found
   → Run: php artisan route:clear

Lihat INSTALLATION.md untuk troubleshooting lengkap!
