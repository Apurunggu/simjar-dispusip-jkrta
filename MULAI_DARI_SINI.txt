🚀 CARA MEMULAI (PALING MUDAH):

1. Buka Command Prompt atau PowerShell

2. Ketik perintah ini:
   
   cd c:\xampp\htdocs\Simjar_dispusip
   composer install
   php artisan migrate --seed

3. Tunggu sampai selesai (2-3 menit)

4. Buka browser dan akses:

   http://localhost/Simjar_dispusip/public

SELESAI! Aplikasi sudah siap digunakan! ✅

✨ FITUR APLIKASI:

1. DASHBOARD
   • Lihat statistik barang dan perangkat
   • Grafik perangkat per bulan

2. BARANG MASUK
   • Tambah barang → Edit → Hapus → Lihat detail
   • Export data ke PDF

3. PERANGKAT JARINGAN
   • Tambah perangkat → Edit → Nonaktifkan
   • Filter berdasarkan lokasi
   • Lihat log aktivitas perangkat

❓ PERTANYAAN SERING DIAJUKAN:

Q: Bagaimana kalau terjadi error saat install?
A: Baca file INSTALLATION.md bagian "Troubleshooting"

Q: Apa yang dibutuhkan untuk menjalankan aplikasi ini?
A: - XAMPP (sudah terinstall?)
   - Composer (sudah terinstall?)
   - Browser (Chrome, Firefox, Edge)

Q: Database sudah ada atau harus dibuat?
A: Otomatis dibuat saat Anda jalankan: php artisan migrate

Q: Bagaimana cara export data ke PDF?
A: Di halaman "Barang Masuk", klik tombol "Export PDF"

Q: Bagaimana cara filter perangkat?
A: Di halaman "Perangkat Jaringan", gunakan dropdown filter "Lokasi"
